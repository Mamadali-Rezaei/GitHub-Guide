# راهنمای Git و GitHub برای دانشجویان

## معرفی پروژه
این مخزن در راستای انجام تمرین گروهی درس مهندسی نرم‌افزار (استاد مربوطه: دکتر امید ادیب‌فر) ایجاد شده است. هدف این پروژه تهیه یک مستند آموزشی جامع و کاربردی برای آشنایی دانشجویان با مفاهیم کنترل نسخه (Git) و توسعه تیمی در پلتفرم GitHub است.

## Project Goal (هدف پروژه)
مستندسازی و آموزش گام‌به‌گام ابزار Git و GitHub برای درس مهندسی نرم‌افزار (استاد امید ادیب‌فر).
